# Dify-ассистент «Чат с ИИ по карточкам УСВО»

Готовый экспорт приложения лежит в корне репозитория — **`usvo_chat_assistant.yml`**.
Импортируйте его в Dify (Create App → Import DSL), выберите свой датасет карточек УСВО
в узле «Карточки УСВО (база знаний)» (плейсхолдер `REPLACE_WITH_USVO_AI_DATASET_ID`),
опубликуйте и пропишите ключи в `config.yaml` (см. ниже). Раздел ниже описывает, как
приложение устроено, если хочется собрать его вручную.

Создайте отдельное приложение типа **Chat/Chatflow**, подключите к нему отдельную
базу знаний с карточками УСВО и укажите ключи в `config.yaml`:

```yaml
dify:
  usvo_ai:
    app_key: "app-..."
    dataset:
      api_key: "dataset-..."
      dataset_id: "..."
```

Микросервис автоматически создаёт в датасете:

- отдельный документ `Карточка УСВО #<id>: <ФИО>` для каждой актуальной карточки;
- документ `Мета-информация УСВО` с текущими агрегатами.

Специальные input-переменные в Dify не требуются: текущий вопрос, история диалога,
мета-информация и инструкция формата передаются в поле `query`. В приложении Dify
нужно включить Knowledge Retrieval по указанному датасету и подать найденный контекст
в LLM.

## Системная инструкция

```text
Ты ассистент, который отвечает на вопросы пользователей по базе карточек УСВО.

У тебя есть:
1. база знаний с карточками людей;
2. мета-информация о текущем состоянии базы карточек;
3. история диалога пользователя;
4. выбранный формат ответа.

Правила:
- Отвечай только на основе доступных данных.
- Если данных недостаточно, прямо скажи, каких данных не хватает.
- Не выдумывай людей, категории, статусы или числа.
- Если вопрос статистический, используй мета-информацию и найденные данные.
- Если вопрос про конкретных людей, используй данные карточек.
- Если в ответе упоминаешь человека из карточек УСВО, пиши его полное ФИО.
- Форматируй ответ согласно выбранному типу ответа: текст, развернутая справка или краткая справка.
- Для краткой справки отвечай максимально сжато.
- Для развернутой справки используй официальный структурированный формат.
```

Эта же инструкция и точные шаблоны трёх форматов продублированы на backend в
`app/web/ai_chat.py`, поэтому формат сохраняется даже при минимальном системном
промпте Dify.
