# База знаний: стили оформления «Истории взаимодействия» УСВО

Этот документ — справочник для LLM-ассистента, который нормализует свободный текст
«Истории взаимодействия» из карточки участника СВО в структурированный JSON для
красивого отображения в веб-кабинете «Контакт-центр».

Загрузите этот файл как документ в базу знаний Dify и подключите её к ассистенту
`history_assistant.yml`. Модель опирается на категории, статусы и стили ниже и
возвращает **строго JSON** по схеме из раздела «Формат ответа».

---

## Категории события (`kind`) → иконка на интерфейсе

| kind | Когда использовать | Иконка |
|----------|--------------------------------------------------------------|--------|
| `status` | Постановка на учёт, реестр, статус «Ветеран боевых действий», военкомат, удостоверения | щит |
| `contact`| Обзвон, телефонный звонок, актуализация контактов, опрос | телефон |
| `doc`    | Оформление документов, справок, выплат, компенсаций, заявлений, визит в МФЦ/Госуслуги | документ |
| `med`    | Медицина, реабилитация, санаторий, лечение, ТСР, диспансеризация, МСЭ, ИПРА | крест |
| `work`   | Трудоустройство, вакансии, работодатель, центр занятости, трудовой договор | портфель |
| `edu`    | Обучение, переобучение, переподготовка, курсы, повышение квалификации | диплом |
| `org`    | Ветеранские организации, ассоциация, наставничество, «Время Героя», мероприятия | сообщество |
| `family` | Семья, дети, супруга, пособия на детей, детсад, школа, питание | семья |
| `housing`| Жильё, ЖКУ/ЖКХ, газификация, ремонт, субсидии, земельный участок, ИЖС | здание |
| `visit`  | Личный приём, очный визит, личная встреча | здание/приём |
| `appeal` | Обращение, вопрос, жалоба, консультация через контакт-центр | чат |
| `award`  | Награды, ордена, медали, благодарность командования, поручение Главы округа | медаль |
| `info`   | Прочее, что не подходит к категориям выше | инфо |

## Статус события (`status`) → цвет бейджа

- `выполнено` — действие завершено (зелёный).
- `в работе` — оформляется, подано, на рассмотрении, в процессе (акцентный).
- `запланировано` — назначено на будущее, ожидается, предстоит (синий/сиреневый).

## Акцент события (`style`) → подсветка точки на ленте

- `ok` — успешно (по умолчанию для `выполнено`).
- `accent` — в процессе (по умолчанию для `в работе`).
- `planned` — запланировано (по умолчанию для `запланировано`).
- `warn` — требует внимания (есть нюанс, частичный отказ, нужно уточнение).
- `danger` — проблема (отказ, задолженность, просрочка, нарушение, жалоба).
- `info` — нейтрально.

Если в тексте есть слова **отказ, проблема, задолженность, просрочка, нарушение,
жалоба, приостановлено** — поднимите `style` до `warn` или `danger`.

## Формат ответа (строгий JSON, без markdown-обёртки)

```json
{
  "events": [
    {
      "date": "12.03.2026",
      "kind": "med",
      "status": "выполнено",
      "style": "ok",
      "title": "Краткий заголовок события (до 8 слов)",
      "detail": "Развёрнутое описание одним-двумя предложениями.",
      "org": "Учреждение (если упомянуто, иначе пустая строка)"
    }
  ]
}
```

Правила:
1. Разбейте свободный текст на ОТДЕЛЬНЫЕ события (по датам, переносам строк,
   точкам с запятой, смыслу). Одно действие = одно событие.
2. `date` — в формате ДД.ММ.ГГГГ, если дата есть в тексте; иначе пустая строка.
3. `title` — короткий, человекочитаемый. `detail` — аккуратно переформулированный
   фрагмент исходного текста (без воды, грамотно).
4. `kind`, `status`, `style` — строго из списков выше.
5. Не выдумывайте факты, которых нет в тексте. Только нормализуйте и оформляйте.
6. Верните события в хронологическом порядке (старые → новые).

## Примеры

**Вход:**
> 12.03.2026 прошел реабилитацию в госпитале, выдали направление на ТСР. Записан
> на санаторий на апрель. Трудоустроен водителем с 20.03.

**Выход:**
```json
{
  "events": [
    {"date": "12.03.2026", "kind": "med", "status": "выполнено", "style": "ok",
     "title": "Реабилитация в госпитале", "detail": "Пройден курс реабилитации, выдано направление на технические средства реабилитации (ТСР).", "org": "Госпиталь для ветеранов войн"},
    {"date": "", "kind": "med", "status": "запланировано", "style": "planned",
     "title": "Путёвка в санаторий", "detail": "Записан на санаторно-курортное лечение на апрель.", "org": ""},
    {"date": "20.03.2026", "kind": "work", "status": "выполнено", "style": "ok",
     "title": "Трудоустройство водителем", "detail": "Трудоустроен водителем с 20.03.2026.", "org": ""}
  ]
}
```

**Вход:**
> отказ в выплате компенсации ЖКУ, нужна справка о составе семьи

**Выход:**
```json
{
  "events": [
    {"date": "", "kind": "doc", "status": "в работе", "style": "danger",
     "title": "Отказ в компенсации ЖКУ", "detail": "Получен отказ в выплате компенсации ЖКУ — требуется справка о составе семьи.", "org": ""}
  ]
}
```
