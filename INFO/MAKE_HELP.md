# MAKE_HELP.md — как сделать шаблон заявления на меру поддержки

Это инструкция для **администратора**: как подготовить файл-шаблон заявления, который бот MAX
автоматически заполнит данными из фотографий документов гражданина.

Готовый пример лежит в папке [`template/`](template/Zayavlenie_mera_primer.docx) — откройте его в Word,
чтобы увидеть разметку «вживую».

---

## 1. Что такое шаблон

Шаблон — это обычный документ **Word (`.docx`)** вашего заявления, в который вместо конкретных
данных вставлены **поля-плейсхолдеры** в двойных фигурных скобках:

```
Заявитель: {{full_name}}
Паспорт: серия {{passport_series}} № {{passport_number}}
Адрес регистрации: {{registration_address}}
```

Когда гражданин оформляет меру в боте, система:
1. распознаёт его документы по фото;
2. подставляет распознанные значения вместо `{{...}}`;
3. недостающие поля запрашивает у гражданина текстом;
4. формирует готовый `.docx` и присылает на подтверждение.

---

## 2. Формат разметки полей

- Поле пишется так: **`{{ключ}}`**, где `ключ` — латиницей, в нижнем регистре, слова через
  подчёркивание (`snake_case`): `{{full_name}}`, `{{bank_account}}`, `{{passport_series}}`.
- Разрешены буквы `a–z`, цифры `0–9` и `_`. Пробелы, кириллица и дефисы в **ключе** недопустимы
  (они в человекочитаемой подписи — см. ниже).
- Один и тот же ключ можно использовать в шаблоне несколько раз — подставится одно значение
  во все места (удобно для ФИО в шапке и в строке подписи).

> **Важно (особенность Word).** Вписывайте `{{ключ}}` **одним набором, не меняя форматирование
> внутри скобок**. Если выделить часть плейсхолдера курсивом/жирным или поставить курсор в
> середину и продолжить печать, Word может «разорвать» текст на части, и поле не распознается.
> Если поле не подхватывается — удалите его и наберите заново целиком.

Где можно ставить плейсхолдеры: в обычном тексте, в **таблицах**, в **колонтитулах** (верх/низ
страницы). Вся вёрстка, шрифты, печати и таблицы сохраняются — меняются только значения полей.

---

## 3. Какие поля доступны

Ключи вы придумываете **сами** под свою форму — жёстко зашитого списка нет. Чтобы распознавание
по фото работало точнее, для типовых данных используйте ключи из таблицы ниже (по ним модель
понимает, что искать). Любые другие поля тоже можно — если их не удастся распознать, бот просто
попросит гражданина прислать их текстом.

| Ключ (`{{...}}`)                    | Что это                                   | Откуда берётся          |
|-------------------------------------|-------------------------------------------|-------------------------|
| `full_name`                         | ФИО заявителя                             | паспорт                 |
| `birth_date`                        | Дата рождения (ДД.ММ.ГГГГ)                | паспорт                 |
| `passport_series`                   | Серия паспорта                            | паспорт                 |
| `passport_number`                   | Номер паспорта                            | паспорт                 |
| `passport_issued`                   | Кем и когда выдан паспорт                 | паспорт                 |
| `registration_address`              | Адрес регистрации                         | паспорт                 |
| `snils`                             | СНИЛС                                      | СНИЛС                   |
| `inn`                               | ИНН                                       | свидетельство ИНН       |
| `phone_number`                      | Контактный телефон                        | со слов / ввод текстом  |
| `email`                             | Электронная почта                         | ввод текстом            |
| `bank_name`                         | Наименование банка                        | реквизиты счёта         |
| `bank_account`                      | Номер банковского счёта                   | реквизиты счёта         |
| `military_office_certificate_date`  | Дата справки / постановки на воинский учёт| справка из военкомата   |

Можно добавлять любые свои: `{{child_full_name}}`, `{{injury_date}}`, `{{award_name}}` и т. п.

## 4. Человекочитаемые подписи к полям

В карточке меры (кабинет → «Заявления» → «Меры поддержки») у каждого поля есть **подпись** —
понятное название на русском (например, ключ `military_office_certificate_date` → подпись
«Дата справки из военкомата»). Подпись:
- помогает гражданину понять, что именно прислать, когда поле не распозналось;
- помогает ИИ точнее извлечь значение с фото.

При загрузке шаблона система **сама находит все `{{ключи}}`** и предлагает их список — вам остаётся
поправить подписи. Подписи можно отредактировать в любой момент.

---

## 5. Как завести меру и загрузить шаблон

1. Войдите в кабинет администратором → раздел **«Заявления»** → вкладка **«Меры поддержки»**.
2. Нажмите **«Новая мера»** и заполните:
   - **Название** (его увидит гражданин в боте, напр. «Единовременная выплата»);
   - **Описание** — кратко, кому и при каких условиях положена;
   - **Подсказка для ИИ** — ключевые слова/ситуации, по которым ИИ выберет эту меру в ответ на
     свободный вопрос гражданина (напр. «ранение, госпиталь, единовременная выплата»);
   - **Требуемые документы** — добавляйте по одному кнопкой **«+»** (Паспорт, СНИЛС, Справка из
     военкомата, Реквизиты счёта …). Именно эти документы бот будет запрашивать по очереди фото.
   - **Поля шаблона** — заполнятся автоматически после загрузки шаблона; подписи можно поправить.
3. Загрузите **`.docx`-шаблон** (блок «Шаблон заявления»). Система распознает плейсхолдеры и
   привяжет их к мере.
4. Поставьте галочку **«Активна»** и сохраните.

После сохранения мера сразу:
- появляется в боте MAX (кнопка/команда «Оформление мер поддержки»);
- автоматически выгружается в **базу знаний** — её сможет подобрать ИИ по описанию ситуации
  (нужно лишь, чтобы в конфиге были заполнены `dify.dataset.api_key` и `dify.dataset.dataset_id`).

## 6. Чек-лист хорошего шаблона

- [ ] Файл в формате **`.docx`** (не `.doc`, не PDF).
- [ ] Все заполняемые места заменены на `{{snake_case}}`-плейсхолдеры.
- [ ] Плейсхолдеры набраны целиком, без разрыва форматированием.
- [ ] Для типовых данных использованы ключи из таблицы раздела 3.
- [ ] Список требуемых документов в карточке меры соответствует тому, что нужно для полей.
- [ ] Шаблон загружен, в карточке меры видны распознанные поля, подписи на русском поправлены.
- [ ] Мера отмечена как «Активна».
